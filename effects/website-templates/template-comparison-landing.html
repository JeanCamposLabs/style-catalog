Catalogue vs. hand-rolled snippets

Both work. The difference is what happens after the first month.

Style Catalog
  • One file per effect
  • Machine-readable metadata
  • Validated accessibility notes
Personal snippets
  • Zero setup
  • Exactly your conventions
  • No search, no metadata
VerdictKeep your snippets for one-offs. Use the catalogue when more than one person, or one agent, has to find the effect again.
